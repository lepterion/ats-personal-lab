# Префіксне дерево (Trie) з автодоповненням

Лабораторна робота №2 з дисципліни «Алгоритми та складність», **варіант 3**.

> Реалізуйте структуру даних Префіксне дерево (Trie) для збереження словника унікальних слів. Дерево має підтримувати операції додавання слова, видалення слова та пошуку. Реалізуйте функцію автодоповнення (autocomplete): за заданим префіксом (наприклад, "про") програма має за оптимальний час знайти та вивести на екран топ-5 найкоротших слів з дерева, що починаються на цей префікс.

Виконав: Петренко Богдан Олександрович, група ІПС-22.

## Коротко

- Дерево зберігає українські слова посимвольно (кодові точки Unicode, не байти UTF-8).
- Кожен вузол тримає кеш: 5 найкращих (найкоротших, за рівної довжини за абеткою) слів свого піддерева. Тому автодоповнення = спуск по префіксу + читання кешу: **O(|p| log σ + 5)**, незалежно від кількості слів з цим префіксом.
- Для порівняння є автодоповнення пошуком у ширину без кешу та повний перебір списку.
- Словник: 338 829 українських лем із [brown-uk/dict_uk](https://github.com/brown-uk/dict_uk) (`data/uk_words.txt`).

Звіт: [`docs/REPORT.md`](docs/REPORT.md) (і `docs/REPORT.docx`).

## Збірка й запуск

Потрібні компілятор C++17 і CMake ≥ 3.16. Сторонніх бібліотек немає.

```
cmake -S . -B build
cmake --build build --config Release
./build/trie_tests          # юніт-тести (Windows: build\Release\trie_tests.exe)
./build/trie_app            # програма; шукає data/uk_words.txt у поточній теці або вище
./build/trie_app words.txt  # свій словник (одне слово в рядку, UTF-8)
```

На Windows програма сама перемикає консоль на UTF-8.

## Структура

| Файл | Що в ньому |
|------|-----------|
| `src/Trie.h/.cpp` | префіксне дерево: `insert`, `remove`, `contains`, `hasPrefix`, `autocomplete` (кеш), `autocompleteBfs`, `allWords`, `checkInvariants` |
| `src/Utf8.h/.cpp` | UTF-8 ↔ UTF-32, порядок української абетки, нормалізація слів (регістр, апостроф) |
| `src/Dictionary.h/.cpp` | завантаження словника з файлу чи потоку |
| `src/Benchmark.h/.cpp` | перебір без дерева (`autocompleteBruteForce`) і порівняння часу |
| `src/main.cpp` | консольне меню |
| `tests/tests.cpp` | 17 юніт-тестів, зокрема рандомізована перевірка проти перебору |
| `tools/prepare_dictionary.py` | як отримано `data/uk_words.txt` |
| `tools/make_report_docx.py` | генерує `docs/REPORT.docx` з `docs/REPORT.md` (потрібен `python-docx`) |

## Словник

`data/uk_words.txt` отримано з `dict_corp_vis.txt` релізу v6.8.6 проєкту brown-uk/dict_uk (ліцензія GPL-3.0): лише леми, записані українськими літерами, без власних назв, абревіатур, лайливих, рідковживаних і застарілих слів. Команда: `python3 tools/prepare_dictionary.py dict_corp_vis.txt data/uk_words.txt`.
